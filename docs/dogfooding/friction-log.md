# Friction log — MVP9 dogfooding week

Not a feature spec. A running, low-effort record of where real daily use of
Friday rubbed — kept so MVP10+ scoping is driven by what actually happened,
not by what the roadmap guessed. Started 2026-07-14.

Two ways to add an entry, whichever is less friction in the moment:

1. **Tell Claude Code** ("friction: <what happened>") in any session — it
   appends an entry here immediately, dated, with no other ceremony.
2. **Note it in Friday itself** (web chat, Telegram, or CLI), prefixed
   `friction:` — it's just a normal note, searchable/exportable like any
   other. At the end of the week, ask Claude Code to pull every `friction:`
   note out of Memory and fold it into this file. This has the side effect
   of dogfooding the note-taking/search path *while* using it to log
   friction with the note-taking/search path — if that path itself is
   annoying to use for this, that's a finding too.

Either way, capture just enough to be useful later — not a bug report:

```
## <date> — <channel: panel/telegram/cli>
**Doing:** what you were trying to do
**Expected:** what you assumed would happen
**Got:** what actually happened
**Severity:** blocker / annoying / minor
```
